Duckie Days 24.297

Sock Gremlin Fashion Battle

- Added Sock Gremlin as a seventh equal-weight gimmick encounter while playing Duck Quest as Miko.
- Sock Gremlin can appear in any normal stage through the existing rare gimmick roll and shared cooldown.
- Added Base, Blue, Pink, Black, Gold, and Shiny Sock Gremlin art.
- Accepting its challenge safely suspends the current Duck Quest run and transports the player to Miko's Closet.
- The challenge generates three basic style prompts only from Miko wardrobe tags that are achievable with currently owned clothing.
- A Done button scores the finished outfit from 1–3 hearts and returns to the exact Duck Quest run.
- Higher ratings grant better Pink Coin rewards, better EXP Candy chances, and better odds for the Sock Gremlin Trading Card.
- The judge screen requires Continue before advancing to the next encounter/floor, so the run is never discarded.
- Added Rare card R-047: Sock Gremlin.

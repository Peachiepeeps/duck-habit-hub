Duckie Days v24.311

This package merges the pending v24.310 fixes into the new Universal Clothing system.

Universal clothing ownership behaves like paintable furniture: you may own duplicates, and each copy remembers its own colors. White is the default.

Socks:
- Shop and Closet preview both socks together.
- Each owned pair can be worn Off, Left, Right, or Both.
- Different owned sock copies can be layered at the same time.
- Existing stockings/legwear are not removed.

Fashion encounter drops:
- Sock Gremlin now has a score-based chance to drop one random Universal Clothing copy.
- A reusable DuckieUniversalClothingDropsV311 helper is included for Bownny to use when that encounter is present/wired into the repository.

Also includes the previously prepared fixes for card reward display, temporary Sock Gremlin closet outfits, and Lucky Gift Box Mimic battle sprites.

Duck Habit Hub v24.73 — Buddy Pons & Buddy Collection

NEW — BUDDY PONS
- Replaced the old placeholder Buddy Pon art with the user's new capsule designs.
- Buddy Pon (pink): 50 Pink Coins, 50% catch chance on normal enemies.
- Super Buddy Pon (purple): 100 Pink Coins, 75% normal / 35% boss catch chance.
- Boss Buddy Pon (gold): 175 Pink Coins, 100% normal / 70% boss catch chance.
- Any Buddy Pon will be a guaranteed catch on a Shiny Buddy.
- All three Buddy Pons can also appear as treasure-chest item rewards. Pink is most common, purple is uncommon, and gold is rare.

NEW — CATCHING
- After defeating an enemy or boss, Duck Quest pauses before the victory chest.
- The player gets one Buddy Pon attempt or can continue without using one.
- Failed attempts consume the Buddy Pon; successful attempts add the Buddy to the collection.
- Buddies can be caught multiple times and track an Owned ×# quantity.
- A normal Buddy Pon cannot be used on a normal boss; Super and Boss Buddy Pons can.
- Shiny bosses will accept any Buddy Pon because Shinies are guaranteed catches.

NEW — BUDDY BOOK
- Duck Quest now has a Buddy Collection / Buddy Book screen.
- Current known enemy recolors appear as collection slots; uncaught entries are silhouettes marked ???.
- Filters: All / Normal / Boss / Shiny.
- Caught entries show Owned ×#.
- Tap a Buddy to see a larger detail card.
- Profiles now include a View Buddy Collection button.

UPDATED — PROFILE BUDDIES
- Duplicate catches matter: the same Buddy species can be assigned to multiple profile slots/OCs only when enough physical copies are owned.
- Existing v24.72 Buddy records migrate to quantity ×1 automatically.

SHINY FOUNDATION
- Shiny chance is set to 1/100 per eligible enemy-family encounter.
- Each enemy family uses ONE special shiny recolor that can replace any normal recolor from that family.
- Shiny is not tied to a specific normal color.
- Shiny names receive an animated sparkle in the nameplate.
- No shiny art is bundled in v24.73 yet, so shiny spawning stays dormant until special recolor assets are added to the SHINY_VARIANTS map.

NOT YET IN THIS STEP
- Main Buddy appearing as an NPC battle helper.
- Buddy button / Buddy Skills.
- Expanded OC moves and moving Quick Heal into Attack.
- Endless Mode.
- Quest Charms / Friendship Charm.
- Shiny trophies.

SAVE SAFETY
- Uses the same localStorage save key as previous versions.
- Existing progress is preserved.

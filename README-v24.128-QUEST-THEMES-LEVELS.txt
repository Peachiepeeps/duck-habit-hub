Duckie Days v24.128 — Duck Quest UI Themes + RPG wording

NEW
- UI Themes menu added to Duck Quest.
- Classic Cream is always available.
- OC themes unlock by clearing Meadow Level 10 with that OC:
  Peep Picnic, Miko Moonlight, Io Sweetheart, Miho Tea Room, Annika Crimson.
- Stage themes unlock at milestone clears:
  Meadow Bloom — Meadow Level 20
  Ocean Breeze — Ocean Level 40
  Candy Pop — Candyland Level 60
  Cloud Dream — Cloud Garden Level 80
- Theme unlocks are permanent and global once earned.
- Existing saves retroactively receive any themes whose requirements they already completed.

BUDDY BOOK
- Befriended variations now have a “Use as Book Icon” control.
- The chosen normal form becomes that family’s portrait on Meadow/Ocean/Candyland/Cloud Garden tabs.
- Shiny portrait selection is stored separately from the normal family portrait.

TERMINOLOGY / SURPRISE REWARDS
- User-facing Rank -> Level.
- User-facing Area -> Stage.
- “Charm Loadout” -> “Equip Charm.”
- Stage buttons now show only their Level range, not the completion reward.
- Final-Level descriptions no longer reveal the completion accessory before it is earned.

SAVE SAFETY
- Internal save fields retain legacy area/rank key names for compatibility with existing saves.

# Bao Cafe Planning Pack

This planning pack is for the Duckie Days Bao Cafe minigame concept.

It contains:
- portrait layout specification
- gameplay logic specification
- recipe list and bear mechanics
- Duck Quest encounter flow notes
- recommended file/folder plan
- reference art files supplied by the user

This pack is a **planning/reference pack**, not the full playable feature implementation yet.
It is meant to be stored in the repository for reference before the real Bao Cafe feature update is built.

Suggested install folder in repo:
- `bao-cafe-planning/`

Current game repo version when this was prepared:
- `v24.298`

Planned future feature package:
- `v24.299 Bao Cafe Minigame`

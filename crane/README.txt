Gameplay:
- Only ducks already unlocked in Duckipedia can appear.
- Five ducks appear per machine.
- If 5+ ducks are unlocked, a restock uses five different ducks.
- Successful catch: +3 Pink Coins.
- Clear all five: +10 additional Pink Coins.
- RESTOCK: 10 Pink Coins.
- Ducks are NOT duplicated or added to inventory; the crane uses them as visual prizes only.
- The wire is CSS, not an image.
